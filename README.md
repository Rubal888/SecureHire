# SecureHire
SecureHire is a secure online hiring assessment platform designed to help companies conduct remote recruitment tests with camera monitoring and anti-cheating controls.
## Features
- Online hiring assessments
- Camera monitoring
- Anti-cheating system
- Timed tests
- Secure test environment
- Recruiter dashboard
- Pricing plans
- Responsive landing page
## Technologies Used
- Html, CSS and Javascript and React (future implementation)
- CSS
- Javascript
- React (future implementation)
## Project Goal
The goal of SecureHire is to simplify remote hiring by providing companies with a secure platform to assess candidates online.
